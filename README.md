# M3U Collector Web

Reimplementação web independente das funções observadas no **M3uCollector V5.2**.

## Incluído
- Até 5 servidores Xtream.
- Teste de conexão.
- Coleta de canais, filmes e séries.
- Categorias/grupos.
- Filtro por nome/grupo.
- Seleção individual ou em massa.
- Geração e download de M3U.
- O executável original permanece intacto.
- Não reproduz os endpoints externos de licença/upload encontrados no executável.

## Executar

Node.js 18+:

    npm start

Abra http://localhost:3000.

## Evolução planejada
Importação de M3U, agrupamento, deduplicação, edição de nomes/logos, histórico e autenticação do painel.
